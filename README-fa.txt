ساخت APK برای اندروید باکس / اندروید TV
=====================================
روش ۱ (بدون نصب چیزی، با GitHub):
 1. یک مخزن (repo) خالی در GitHub بسازید و محتوای همین پوشه را (همراه پوشه .github) در آن آپلود کنید.
 2. به تب Actions بروید؛ «Build APK» خودکار اجرا می‌شود (یا Run workflow بزنید).
 3. بعد از چند دقیقه، از پایین صفحه اجرا فایل ClassGames-apk را دانلود کنید؛ داخلش app-debug.apk است.
روش ۲ (Android Studio): این پوشه را Open کنید و Build > Build APK(s) بزنید.
نصب روی باکس: APK را با فلش یا برنامه‌هایی مثل Send Files to TV / Downloader منتقل و نصب کنید (Unknown sources را روشن کنید).
کنترل: با کلیدهای جهت‌دار ریموت حرکت می‌کنید و با OK انتخاب؛ دکمه Back پنجره را می‌بندد یا به خانه برمی‌گردد.
خروجی ویرایشگر (JSON/CSV) در حافظه برنامه ذخیره می‌شود و مسیرش نمایش داده می‌شود.
